  集中修掉“会丢答案 / 会多跑章 / 边界崩溃”的问题。

**修复**
1. 档案写回（最关键）：
   - 卡片名与档案名不完全一致时（如「Java面向对象（二）」vs「…（二） - 封装、继承和多态」），

   无交互环境（EOF）给出明确提示；章节片段未命中、候选编号非法时退出码 2。
5. 配置/状态：`-c` 指向不存在的配置直接报错；answers 相对路径按配置文件目录解析；
   配置类型/端口/超时校验；state.json 损坏自动备份为 `.bad` 并重建；槽位 new/1new 清理 running 记忆。
6. 浏览器/代码写入：复用的浏览器若档案槽不一致会自动重启；多文件写入优先按完整路径匹配，
   basename 同名歧义时报错，避免写错文件。
7. 代码答案清理：CRLF 统一为 LF，拒绝 TOML 不允许的控制字符。

### v0.9.6 · 2026-10-16 · 评测冷却等待 + 灰按钮检测（修「假成功」）

**背景**
- 用户的 run 在选择题关卡住：**评测按钮处于冷却（灰色 / `NN S`）时点击是静默无效的**（连事件都不派发）；
- 旧 `click_eval` 只要「找到了按钮」就返回 True（灰色按钮 `.click()` 无效但元素存在），调用方又忽略返回值
  → 假成功 → 要么干等 180 秒超时，要么被扩展的假跳骗过去，出现「已经评测了但没有检测到关卡变化」。

**改动（答题.py）**
1. `STATE_JS` 增加 `evalDisabled`（评测按钮是否灰色）；
2. 新增 `Page.wait_eval_ready(timeout)`：轮询等按钮变回可点（处理冷却 / `NN S`），首次发现不可点会打日志；
3. `click_eval` 重写：先 `wait_eval_ready` → 点击 → **「按钮被点灰」也算评测已开始** → 兜底前再等一次冷却 → 两次尝试无任何证据就返回 False；
4. `process_chapter` 调用处：`click_eval()` 返回 False 时暂停报错（不再无声继续）。

**验证**
- 已通过关实测：`wait_eval_ready` 就绪即时 True；`click_eval` 点击后 1 秒内捕获「按钮变灰」并返回 True；

### v0.2 · 2026-10-02 · 通用档案 + 完整实测 + 四个 bug 修复

**背景**
- 用户提出：**答案档案要通用**——不要记录"哪些关卡已通过/要跳过"（没有 skip 字段），
  由脚本运行时查详情页状态自动跳过；这样同一份档案可以给进度不同的人用。

**改动**
- `scan` 不再生成 `skip = true`：档案只保留「章节顺序 + homework_id + 每关答案」；
  跳过逻辑 100% 由运行时详情页状态（`已通过`/`已提交`）决定；`skip` 仅保留为用户手动逃生口；
- 选择题支持**多选题**（checkbox）：写法 `answer = ["C", "D", ["A", "B", "D"]]`
  （外层每题一项，多选答案是子列表）；
- 修复下列 4 个实测 bug；文档同步更新。

**修复的 bug（都是真实跑出来的）**
1. **上一关提示语残留骗过最后一关**：扩展的「已为您自动跳转至下一关 😋」在切关后还能活 2.6 秒，
   下一关（尤其最后一关）会被误判为"还有下一关"。
   修复：结果探针给每个 toast 元素打 `__aaSeen` 标记，重置日志不会重复计数；
   且「已跳转」提示不再作为最终信号，必须等"关卡真的变了"；只有「已经是最后一关了」可直接判定 last。
2. **Python 列表 `in` 语义坑**：`TOAST_LAST in toasts` 对列表是**精确匹配**而非子串匹配，
   导致最后一关提示存在却判定超时（等了 180 秒）。
   修复：先 `" ".join(toasts)` 再子串判断。
3. **课堂列表页导航后 React 点击失效**：访问过详情页再返回，卡片按钮点不动。
   修复：每章都用全新课堂标签页（`classroom_page(old=...)`），旧的顺手关掉。
4. **ant-spin 遮罩吞点击 + 详情表格分批渲染**：
   修复：点「开始学习」前等遮罩消失 + `elementFromPoint` 校验 + 最多 4 次重试；
   抓详情表格时按课堂卡片 `x/y` 等行数补齐（否则八章会漏掉第 6 关）。

**另外处理**
- 同名关卡：八章有两个「选择题」、名字匹配会撞车 → 档案匹配改为**以关卡序号为准**，名字仅作校验；
- 注入 JS 的转义：统一 `json.dumps`，避免把字面 `\n` 写进编辑器（曾导致 18 个编译错误）。
