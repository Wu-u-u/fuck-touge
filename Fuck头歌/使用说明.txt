==========================================
  Fuck 头歌 · 使用说明（v2.8.0-beta.3 · 头歌 + 智慧树）
==========================================

【这是什么】
一个按网站加载不同模块的 Edge 浏览器扩展（头歌 + 智慧树）：
  1. 允许粘贴与复制：头歌平时禁止粘贴、还会拦截复制，这个扩展帮你解除；
  2. 阻止头歌侵犯隐私：它会趁你点进代码编辑器时，偷偷往你的剪贴板里写一个
     空格来覆盖你复制的内容，这个行为会被拦截；
  3. 自动下一关：答对通过后，自动点掉庆祝弹窗里的「下一关」/「最后一关」/「完成」，
     并提示「已为您自动跳转至下一关 😋」/「已经是最后一关了 😋」；
  4. 编辑器增强：主题（Catppuccin / GitHub 高对比，默认开启、深浅自动跟随）
     + Maple Mono 字体（内置版仅替换英文/代码符号；想替换中文请自行安装
     Maple Mono NF CN 字体）+ 光标手感（开启 = 柔和闪烁 + 平滑移动，默认关闭；
     关闭时保持页面自带的光标闪烁）。
     用法：点击浏览器右上角的扩展图标打开弹窗，可开关主题、字体、光标动画，
     并在两套主题之间切换；首次进入头歌会询问一次字体；
  5. 页面皮肤（仅答题页面生效）：主题开启时，选择题等没有编辑器的页面也会整页
     换成同一套深色（含左侧任务区、题目代码块）；字体开启时正文/题干一并使用
     Maple Mono，与代码页观感保持一致。主页、目录等页面保持平台原样；
  6. 智慧树视频页：popup 自动切换为智慧树面板，可开启 1.25x、自动连播，
     以及课中单选题/多选题的「正确作答」或「快速作答」。

【安全说明】
  · 头歌模块只作用于 educoder.net；智慧树模块只作用于 *.zhihuishu.com 视频页；
  · 项目完全开源（MIT），不收集、不上传账号/题库/页面内容，全部逻辑在本地运行；
  · 智慧树自动化需要 `debugger` 权限：只在用户启用后向智慧树视频页发送真实鼠标事件，
    避免普通脚本点击被平台判定为异常；停止或离开视频页会 detach；
  · 头歌篡改剪贴板的行为会被拦截，保护你的剪贴板内容不被侵犯。

【2.8.0 智慧树基础版】
  · 打开智慧树视频学习页，点扩展图标会自动显示「Fuck 智慧树」面板；
  · 「正确作答」：先选一个选项，等平台显示正确答案，再改选并提交；
  · 「快速作答」：选一个就关闭，不等待正确答案；
  · 1.25× 倍速、自动下一集、流畅画质可分别开关；
  · 自动下一集下可再开「观看已完成课程」：全部完成后继续重播已完成章节，补观看时长；
  · popup 显示今日实际观看时间，按真实经过时间统计，倍速不加成；
  · 倍速/清晰度优先走播放器原生菜单；菜单不可用时保持原速并提示，不再出现“视频倍速了但 UI 还是 1.0”；
  · 每次切下一集前随机等待 1.031–2.5 秒；播放中偶尔随机暂停约 3 秒；
  · debugger 只在真实点击时短暂 attach，约 1.5 秒后自动 detach；第一次识别到 <video> 会写日志；
  · 右侧显示完成后才切下一节，切完自动起播；
  · 关闭「启动自动化」后其余选项变灰；Edge 的 debugger 提示条会随 detach 消失；
  · 检测到安全验证会停手，请手动完成；
  · 只处理视频页课中弹题，不进入考试/作业；真实课程首次使用建议先用一节小课验证。

【使用教程】（Edge 浏览器）
  1. 先把压缩包解压（得到「Fuck头歌」文件夹）—— 必须先解压；
  2. 打开 Edge，点击右上角的「设置」；
  3. 进入「扩展」→「管理扩展」；
  4. 打开左下角的「开发人员选项」；
  5. 点击「加载解压缩的扩展」；
  6. 选中解压出来的「Fuck头歌」文件夹（注意：选文件夹，不是里面的文件）；
  7. 打开头歌页面，刷新一下（F5），即可使用。

【如何更新】（给已经装好的同学）
  1. 下载新的压缩包，解压到别的地方（比如桌面）——不要在扩展文件夹里面解压；
  2. 打开新解压出的「Fuck头歌」，全选里面的内容（manifest.json、允许粘贴.js、
     popup.html、popup.js、fonts.js、fonts 文件夹、图标），复制；
  3. 打开你当初“加载解压缩的扩展”时选的那个「Fuck头歌」文件夹，粘贴并覆盖；
  4. 打开 Edge 扩展页（edge://extensions），点「Fuck 头歌」卡片上的「重新加载」；
  5. 刷新头歌页面即可。开关和设置都不会丢。
  提示：
  · 更新后在扩展页能看到版本号变化（比如 2.1 → 2.2），可用来确认更新成功；
  · 不要删掉整个文件夹、再从别的新位置加载——那样会提示“找不到扩展”；
  · 2.7+ 的壁纸/自定义背景存在扩展本地存储里，按扩展 ID 隔离。
    一定要覆盖原文件夹并点「重新加载」，不要换路径/新文件夹加载，
    否则等于换了一个新扩展，旧壁纸会读不到。
  · 若旧版字体文件夹里有新版已删掉的文件（如中文包），可以无视或手动删除。

【注意事项】
  · 本扩展可能会因为头歌更新而失效，遇到问题可联系作者跟进；
  · 解压时选「解压到当前文件夹」，确保打开「Fuck头歌」文件夹后，第一层
    直接能看到 manifest.json、允许粘贴.js；若解压成了 Fuck头歌/Fuck头歌
    两层，把里层的「Fuck头歌」拖出来用即可。

【常见问题】
  · Edge 提示“找不到此扩展程序”？
    多半是扩展文件夹被移动/删除，或解压成了两层文件夹。把文件放回原来的
    位置（或修正层级）后，在扩展页点一下「重新加载」；若仍不行，完全退出
    Edge 再打开即可。

【2.7.0 正式版：多壁纸、裁剪与切换】
  · 最多 5 张壁纸：添加/删除/选当前；原图完整保留，不再压缩，也不受 8.5MB 总大小限制。
  · 支持 PNG / JPG / WebP / GIF / MP4 / WebM；GIF 和视频保留动画，
    裁剪只记录区域，不破坏原图；GIF/视频动画保留。
  · 静态图、GIF、视频都可拖动/缩放做 16:9 裁剪；
    每张壁纸左上角「裁」可以重新裁剪（原图保留）。
  · 视频较大时裁剪保存会转圈并禁用按钮，等它完成即可，不会重复添加。
  · Ctrl + Alt + W 在答题页循环切换壁纸；切换效果每次随机，参考 Noctalia：
    fade / wipe / disc / stripes / zoom / honeycomb / vortex /
    pixel / diamond / golden / melt / crt，约 1.5 秒。
    支持 WebGL2 时用 GPU 渲染过渡（与 Noctalia 同一套公式，边缘更柔和）；
    不支持或 contain/stretch/减少动态效果时自动回退 CSS。
    wipe 方向、disc/golden 中心、vortex 旋转方向每次随机。
    高级设置里可以把「过渡效果」固定为 12 种之一，默认「随机（每次不同）」；
    「过渡速度」可选快 0.8 秒 / 标准 1.5 秒 / 慢 2.2 秒 / 很慢 3 秒。
    两项都保存在扩展配置里，重载扩展或刷新页面后仍然有效。
  · 移除“背景固定/随页面滚动”开关，统一固定。
  · 大视频/多壁纸首次读取后通过同源 blob URL 交给页面，不再复制几十 MB 字符串；
    页面 IndexedDB 缓存后，后续切换/刷新更快。高级设置里非当前视频只显示 ▶ 占位，选中后才加载。
    删除壁纸后会清理页面里对应的缓存，不会长期积累。
  · Material You 跟随当前壁纸取色；只影响弹窗和高级设置。
    取色会提高一档饱和度，并拉开背景/面板/卡片层次，界面不再发灰。
  · 2.7.1 起取色按图片覆盖率加权，灰白图不会被小面积红色带成红色；
    高级设置 Material You 旁有「重新取色」，可刷新已有壁纸。
  · 本版只作用于 /tasks/... 答题页，且主题开启时生效；视频壁纸已支持。
  · popup 的「高级设置」入口已移到「脚本状态」上方；壁纸提示字号加大。
  · 高级设置背景大预览会叠一个简化的头歌答题界面（左侧任务、右侧代码、底部测试结果），
    拖动「图片透明度 / 面板不透明度 / 编辑器不透明度」或切换「填充方式」时会实时变化；
    右侧内容区最大宽度 900 → 980px。

【2.6.0 更新：刷题脚本状态与日志】

    已停止（灰）/ 脚本错误（红）。

    只展示当前槽位，不显示其他槽位，也没有启动/停止按钮。

    收尾的「浏览器保持打开，可自行检查」不会再占日志位置。

  · 状态由答题脚本主动上报，插件本身不会启动或停止脚本。
