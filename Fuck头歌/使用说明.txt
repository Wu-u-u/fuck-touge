==========================================
  Fuck 头歌 · 使用说明（v2.5.0）
==========================================

【这是什么】
一个只作用于头歌（educoder.net）的浏览器扩展：
  1. 允许粘贴与复制：头歌平时禁止粘贴、还会拦截复制，这个扩展帮你解除；
  2. 阻止头歌侵犯隐私：它会趁你点进代码编辑器时，偷偷往你的剪贴板里写一个
     空格来覆盖你复制的内容，这个行为会被拦截；
  3. 自动下一关：答对通过后，自动点掉庆祝弹窗里的「下一关」/「最后一关」/「完成」，
     并提示「已为您自动跳转至下一关 😋」/「已经是最后一关了 😋」；
  4. 编辑器增强：主题（Catppuccin / GitHub 高对比，默认开启、深浅自动跟随）
     + Maple Mono 字体（内置版仅替换英文/代码符号；想替换中文请自行安装
     Maple Mono NF CN 字体）+ 光标手感（开启 = 柔和闪烁 + 平滑移动，默认关闭；
     关闭时保持页面自带的光标闪烁）。
     用法：点击浏览器右上角的扩展图标打开弹窗，可开关主题、字体、光标动画，
     并在两套主题之间切换；首次进入头歌会询问一次字体；
  5. 页面皮肤（仅答题页面生效）：主题开启时，选择题等没有编辑器的页面也会整页
     换成同一套深色（含左侧任务区、题目代码块）；字体开启时正文/题干一并使用
     Maple Mono，与代码页观感保持一致。主页、目录等页面保持平台原样。

【安全说明】
  · 仅作用于头歌（educoder.net），不会影响其他网页，可以一直开启；
  · 不收集、不上传任何数据，全部逻辑都在你的浏览器本地运行；
  · 头歌篡改剪贴板的行为会被拦截，保护你的剪贴板内容不被侵犯。

【使用教程】（Edge 浏览器）
  1. 先把压缩包解压（得到「Fuck头歌」文件夹）—— 必须先解压；
  2. 打开 Edge，点击右上角的「设置」；
  3. 进入「扩展」→「管理扩展」；
  4. 打开左下角的「开发人员选项」；
  5. 点击「加载解压缩的扩展」；
  6. 选中解压出来的「Fuck头歌」文件夹（注意：选文件夹，不是里面的文件）；
  7. 打开头歌页面，刷新一下（F5），即可使用。

【如何更新】（给已经装好的同学）
  1. 下载新的压缩包，解压到别的地方（比如桌面）——不要在扩展文件夹里面解压；
  2. 打开新解压出的「Fuck头歌」，全选里面的内容（manifest.json、允许粘贴.js、
     popup.html、popup.js、fonts.js、fonts 文件夹、图标），复制；
  3. 打开你当初“加载解压缩的扩展”时选的那个「Fuck头歌」文件夹，粘贴并覆盖；
  4. 打开 Edge 扩展页（edge://extensions），点「Fuck 头歌」卡片上的「重新加载」；
  5. 刷新头歌页面即可。开关和设置都不会丢。
  提示：
  · 更新后在扩展页能看到版本号变化（比如 2.1 → 2.2），可用来确认更新成功；
  · 不要删掉整个文件夹、再从别的新位置加载——那样会提示“找不到扩展”；
  · 若旧版字体文件夹里有新版已删掉的文件（如中文包），可以无视或手动删除。

【注意事项】
  · 本扩展可能会因为头歌更新而失效，遇到问题可联系作者跟进；
  · 解压时选「解压到当前文件夹」，确保打开「Fuck头歌」文件夹后，第一层
    直接能看到 manifest.json、允许粘贴.js；若解压成了 Fuck头歌/Fuck头歌
    两层，把里层的「Fuck头歌」拖出来用即可。

【常见问题】
  · Edge 提示“找不到此扩展程序”？
    多半是扩展文件夹被移动/删除，或解压成了两层文件夹。把文件放回原来的
    位置（或修正层级）后，在扩展页点一下「重新加载」；若仍不行，完全退出
    Edge 再打开即可。

【关于 2.5.0 / 源码构建】
  · 从 2.5.0 起，扩展源码改为 TypeScript + esbuild 构建（D1-D8 重构）；
    普通使用/更新方式不变：解压 zip、加载其中的「Fuck头歌」文件夹即可。
  · 想自己改源码：需要 Node.js ≥ 20，在「Fuck头歌」目录执行
    npm ci && npm run build，再用 Edge 加载生成的 dist 文件夹（详见仓库 README）。
