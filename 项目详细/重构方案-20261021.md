> 前提：不再考虑零依赖；以本机自用为主，允许安装依赖；他人使用自行补依赖。优先可靠性与时限正确。

## 一、CDP 层：Playwright，不用 Rust/PyO3

### 结论
- 选 **Playwright（Python，sync API）**，通过 `connect_over_cdp("http://127.0.0.1:9222")` 接管现有调试 Edge，保留登录态与扩展。
- **不选 Rust/PyO3**：当前瓶颈是平台页面导航/表格弹窗，不是协议层性能；Rust 会增加工具链、PyO3 边界、跨平台 wheel 与调试成本，收益不成立。

### 迁移方式（零行为变化优先）
1. 保留 `Page` / `WS` 对外接口，新增 `eduauto/browser_backend.py` 抽象。
2. 先实现 Playwright 后端适配器（`eval` / `eval_json` / `mouse_move` / `mouse_click` / `call` / `wait_for` / 多标签）。
3. 现有 54+2+43+9+78 项测试全部保留；真机跑 `browser -ls`、`harvest`、`harvest -f`、`run -y` 对比。
4. 行为完全一致后再移除 `cdp.py`；迁移期保留环境变量/配置开关回退。

### 验收
- 同一账号、同一课堂，旧 CDP 与 Playwright 后端的 harvest 结果/耗时/退出码一致。
- 多标签、旧表防护、Monaco 弹窗、扩展 MAIN world 注入均不回退。

## 二、扩展：TypeScript + 模块化 + esbuild

### 结论
- **做**。1363 行 / 68KB 单文件已影响维护；TS 的价值在拆分后体现。
- **不再提交 `dist/`**：`dist/` 加 `.gitignore`，本地 `npm ci && npm run build` 后由 Edge 加载；`package-lock.json` 入库，Node LTS 固定。
- `manifest.json` 放 `src/`，构建时复制到 `dist/`；版本以 manifest 为唯一来源，构建脚本校验与 `package.json` 一致。
- 分享：`npm run package` 生成 zip（dist + 使用说明），他人无需 Node。

### 构建
- **esbuild + `tsc --noEmit`**：多入口 IIFE、CSS text loader、sourcemap；content script 不能用裸 import。
- 不用 Vite（HMR/多入口 MAIN world 复杂）、不用 WXT/Plasmo（框架锁定，收益低）。

### 模块
`shared`（dom / store / types）← `features`（clipboard、paste-guard、attrs、editor、theme/apply/skin/tokenizer、font、cursor、auto-next、choice、prompt、api）← `content/index`；features 不横向 import，用显式工厂/依赖注入。单文件目标 ≤200 行（主题数据可单独拆）。

### 测试
- **Vitest**：设置迁移、空白判定、`suspectTamper`、`claimJump`、popup seq 等纯逻辑。
- **Playwright 扩展 E2E**：`launchPersistentContext` + `--load-extension=dist`，用系统 Edge；覆盖多标签同步、剪贴板、粘贴/剪切/框选、mock 弹层跳关、选择题、设置迁移、popup 连点。
- 保留现有 42/39 harness 与真实 Edge 六项回归作为发布闸门。

### 风险
- `window.Monaco` 无官方类型，需要最小结构接口。
- MAIN world 与隔离世界的 `chrome` API 类型要分开。
- 迁移期保留旧文件直到对应模块验证通过；每步独立 commit。

## 三、执行顺序建议
