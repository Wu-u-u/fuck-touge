# Fuck 头歌 · 后续方向

> 这份只记录未完成/未来可能做的方向，不代表已实现。当前正式版为 v2.6.0。

## 1. AI 做题接口

目标：让 AI 参与读题和生成答案，但浏览器操作继续由现有确定性脚本负责。

优先级：
1. 先做 AI 答案草稿：代码题 / 选择题；
2. UI 预览、人工确认后再写入答案档案；
3. 主观题图片走视觉模型或 OCR；
4. 失败反馈循环最多 2～3 次，避免无意义重试；
5. 最后再考虑 AI 直接操作浏览器（agent 模式）。

## 2. TUI 控制台（已开始）

已落地基础版 `头歌答题脚本/tui.py`（Textual，实验）；后续继续补状态卡片、AI 草稿预览和更完整的任务控制。

建议：
- Textual + 现有 Python 后端；
- 账号/课程/章节/进度面板；
- Harvest / Run / Stop 按钮；
- 实时日志；
- AI 草稿预览；
- 作为 Web UI 之前的低成本控制层。

## 3. 本地 Web UI

如果以后需要图片预览、手机访问、富 AI 对话：

- FastAPI + WebSocket/SSE；
- React/Vite 或轻量前端；
- 复用 TUI 的控制层；
- 只监听 127.0.0.1，不直接暴露公网。

## 4. 暂不做

- Electron/Tauri 打包；
- 云端浏览器；
- 多账号全并发；
- 让 AI 无限制直接点击/提交。
