### v2.7.0-rc.18 · 2026-11-22 · 视觉（Noctalia 过渡 WebGL2 移植）

**问题**
- rc.17 之前 12 种过渡是 CSS/WAAPI 近似：wipe/disc/stripes/honeycomb 等用 clip-path、mask 和 blur 模拟，边缘和节奏与 Noctalia 的 GLSL 不一致；CSS 无法表达 disc 的 aspect 校正、golden 对数螺旋、CRT 的挤压/辉光。

**改动**
- 新增 `features/wallpaper-shader.ts`：把 Noctalia `wallpaper_program.cpp` 的 12 个片元着色器合并为单个 WebGL2 program（`u_effect` 分支），两张纹理 `u_source1/u_source2` + `u_progress`，`u_smoothness=0.3`。
- `coverTransform()` 用 UV 仿射变换复刻 CSS 的 cover + 裁剪布局；`effectParams()` 对齐 Noctalia 默认（stripeCount 12、cellSize 0.04/0.05，wipe 方向/disc 与 honeycomb 中心/stripes 与 golden 角度随机）。

- `custom-visual.ts`：切换时先尝试 GPU 过渡并隐藏旧层（避免低不透明度叠加两次）；返回 `null`、媒体 600ms 内未就绪或 `fit !== cover` 时自动回退原 CSS/WAAPI；完成/取消/`dispose` 都会释放 GL 资源和 canvas。
- 两种路径时长统一为 1.5s；CSS 回退逻辑保留。

**验证**

### v2.6.0 · 2026-11-18 · 功能（自定义背景与页面颜色，测试版）

**测试版说明**
- 2.6.0 先作为测试版发布：背景/颜色只覆盖答题页；beta.1 之后又追加了常用编辑器选项。仍不含全站深色和快捷键。
- 已知观感：左侧默认面板 80%、图片透明度 60%，仍偏克制；觉得淡可把面板不透明度降到 70% 左右。

**背景**
- 用户要的是“整个答题页”而不是只换编辑器：编辑器已经由平台做了深色，扩展负责页面壳、任务区、测试结果区和背景。
- 修正透明度语义：滑块叫“图片透明度”，**数值越高越透明**（100% = 隐藏，0% = 原图）；默认 60%（等价于 CSS 不透明度 40%），画面与之前默认一致。
