### v2.4 · 2026-10-15 · 功能（页面皮肤：无编辑器页面整页深色）

**背景**
- 用户反馈：选择题页“背景主题和字体都没有变”——主题/字体依赖 Monaco 实例，选择题页无编辑器（题干/代码块是平台静态 HTML）；

### v2.1 · 2026-10-02 · 功能（光标手感 + 描述更新）

**改动**
- 弹窗新增第三个开关「**光标动画**」，**默认关闭**，控制 `cursorSmoothCaretAnimation`；
- `cursorBlinking` 改为 `"smooth"`，**无条件默认开启**（评估为纯视觉正向提升）；
- 经评估**不默认开启** `smoothScrolling`（有缓动延迟、非纯正向提升，VS Code 也默认关）；
- `manifest.json` 描述加入"**支持部分美化功能**"（对应浏览器扩展页的简介）；
- `使用说明.txt` 更新至 v2.1：标题版本号、第 4 条改为"主题 + 字体 + 光标手感"并补用法。

**实现要点**
- 新存储键 `fuckTougeCursor`（默认 off）；`set()` API 增加 `cursor` 字段，保持**局部更新**语义；
- 快照分离：`readOrigOptions()` 返回 `{font, cursor}`，编辑器登记为 `{ed, orig: font, cursorOrig: cursor}`；`applyFont()` 用 `orig`、`applyCursor()` 用 `cursorOrig`——**避免"关字体"把光标设置一起还原**（v2.0 架构下的隐患，本次修正）；
- `cursorOptions()`：`cursorBlinking:"smooth"` 恒定；`cursorSmoothCaretAnimation` 仅在 `EditorOption` 存在时下发（老版本降级不报错）；
- 弹窗：第三行开关 `#tc`，副标题注明"平滑移动 · 打字时也会滑动"（该 Monaco 为布尔 API，无 `explicit` 档）；状态推送为完整对象 `{theme,font,themeName,cursor}`。

**验证**（调试实例 + CDP，脚本 `test_v21.py` / `test_popup_v21.py`）
- 开启 → `getOption(cursorSmoothCaretAnimation)=true`；关闭 → 恢复 `false`；
- 加载后 `cursorBlinking=2`（smooth），关闭光标动画后仍为 2；
- 关闭字体开关：字体还原为 `Droid Sans Mono`，**光标两项不受影响**；
- 刷新后 `cursor` 状态持久化；
- 弹窗：初始 cursor=false；点开关推送含 `cursor:true` 的载荷并正确渲染。

## 历史回顾（v1.0 → v2.0，2026-10-01 ~ 10-02 早期）
